# Project skills

The `next-*` folders are copied unchanged from the Next.js repository, `skills/` directory
(https://github.com/vercel/next.js/tree/canary/skills, MIT, commit fac5fc8 of 2026-10-31).
Refresh them by copying the directory again; do not edit them here.

Five of the six need Next.js 16.3 or later (Cache Components, Partial Prefetching, `/_next/mcp`);
the app runs Next.js 16.4 since 2026-10-31. `next-dev-loop` also needs the `agent-browser` CLI
(`npm i -g agent-browser@latest`), which is not installed.
